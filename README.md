# 🏨 Hotel Booking Analysis Dashboard (Power BI)

## 📌 Project Overview
This project focuses on analyzing **hotel booking data** to uncover insights related to booking trends, cancellations, revenue, and customer behavior.  
The dashboard is developed using **Microsoft Power BI** and helps hotel management make **data-driven business decisions**.

---

## 🎯 Purpose of the Project
The main purpose of this project is to:
- Understand hotel booking patterns
- Identify key reasons for booking cancellations
- Analyze revenue and pricing performance
- Compare City Hotel and Resort Hotel performance
- Support strategic planning and operational efficiency

---

## 🛠 Tech Stack
- **Power BI Desktop**
- **Power Query** – Data Cleaning & Transformation
- **DAX (Data Analysis Expressions)** – Measures & Calculations
- **Excel / CSV** – Data Source
- **GitHub** – Version Control & Project Sharing

---

## 📂 Data Source
The dataset used in this project is a **Hotel Booking dataset** containing historical booking records.

### Key Data Fields:
- Hotel Type (City Hotel / Resort Hotel)
- Booking Date & Arrival Date
- Lead Time
- Number of Adults / Children
- Room Type
- Market Segment
- Country
- Booking Status (Canceled / Not Canceled)
- Average Daily Rate (ADR)

---

## ✨ Features / Highlights

### 🔹 Business Problem
Hotels often face challenges such as:
- High cancellation rates
- Seasonal demand fluctuations
- Revenue loss due to inefficient pricing
- Limited visibility into customer booking behavior

---

### 🔹 Goal of the Dashboard
- Track total bookings and cancellations
- Analyze cancellation trends and risk factors
- Compare performance of City Hotels vs Resort Hotels
- Monitor revenue, ADR, and occupancy trends
- Provide actionable insights for decision-makers

---

### 🔹 Walkthrough of Key Visuals
- **Total Bookings KPI** – Displays overall booking volume  
- **Cancellation Rate KPI** – Shows percentage of canceled bookings  
- **Bookings Trend (Monthly/Yearly)** – Identifies seasonal patterns  
- **Hotel Type Comparison** – City vs Resort booking analysis  
- **Country-wise Bookings Map** – Customer geographic distribution  
- **Revenue & ADR Charts** – Pricing and income performance  

---

### 🔹 Business Impact & Key Insights
- City Hotels receive more bookings but have higher cancellation rates  
- Longer lead time increases the probability of cancellation  
- Certain market segments generate higher revenue  
- Seasonal demand strongly affects occupancy and revenue  
- Insights help improve pricing strategy, promotions, and overbooking decisions  

---

## 🚀 How to Use the Dashboard
1. Download the `.pbit` file from this repository  
2. Open it using **Power BI Desktop**  
3. Connect your dataset when prompted  
4. Refresh the data  
5. Explore interactive visuals and insights
